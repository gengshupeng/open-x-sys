# 回放

[English](README.md)

> **给“看一看”用。** 回放，是一次**真实运行**的记录，经运行者同意后公开。

**这个 Alpha Preview 版本里还没有回放。** 回放只从真实运行里添加。这里没有任何东西是为了看起来像一次运行而写出来的。这个文件夹里只有说明文件的时候，直说，并改为提议引导之旅或试一试。

## 一段回放包含什么

回放让人按事情发生的样子，看一次运行：

1. **输入的那句话**，原样。
2. **发现，按到来的顺序**，以及每一个花了多久。
3. **选择的路线**，以及系统为这个选择给出的那一句话。岔路，以及走了哪一边。
4. **成果**，和交付时一样，连同它的分享包。
5. 留下来的**系统入口**。
6. **之后发生了什么**：这个人实际发出的后续问法（如果有）。
7. **背景**：模型、宿主、日期、当时有哪些依赖，以及这次运行花了多久。

## 回放的诚实规则

- **只收真实的运行。** 回放从不是事后重构的，不会被修得看起来更快，也不会由几次尝试拼成。
- **发现不做编辑。** 运行中犯过又纠正了的错误，留在里面。
- **同意。** 公开的内容，由运行者逐项批准。先去掉一切个人内容，个人的根系统从不出现在回放里。
- **是挑选出来的，不是编排出来的。** 可以因为一次真实运行是个好例子而从几次里选中它。不可以事先写好脚本。
- **带日期。** 回放显示的是那一天、那个模型下系统做了什么。后来的版本可能不同。

## 格式

每段回放一个文件夹，以日期和对象命名。里面是：`replay.md`（按顺序写出上面各项）、交付时的成果与分享包，以及系统入口。网站的“看一看”页面读的是同一个文件夹。
