# Support

[简体中文](SUPPORT.zh-CN.md)

Questions, ideas, works, bugs, and security reports each have their own entry so every kind of feedback reaches the system able to act on it.

| Need | Entry |
| --- | --- |
| Usage questions, systems thinking, architecture, ideas, and roadmap | [GitHub Discussions](https://github.com/gengshupeng/open-x-sys/discussions) |
| Show a work, share a run, or exchange practice | [GitHub Discussions](https://github.com/gengshupeng/open-x-sys/discussions) |
| Reproducible bugs, installation trouble, or AI-tool compatibility | [GitHub Issues](https://github.com/gengshupeng/open-x-sys/issues/new/choose) |
| An unpatched security problem | [Private vulnerability report](https://github.com/gengshupeng/open-x-sys/security/advisories/new) |
| A code, documentation, method, or test contribution | [Contribution guide](CONTRIBUTING.md) |

For a question, include your original words, AI tool and model, OpenXSys version, actual result, and the difference you hoped to see. Works can go straight to Discussions. A reproducible problem belongs in the Issue form so it can enter a repair path quickly.
