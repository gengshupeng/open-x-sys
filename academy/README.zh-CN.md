# 学院

[English](README.md)

人们通过使用系统思维来学会它的地方。学院沿着旅程组织：看懂、解释、预见、找准、选择、创造、改进。

**现状。** 这一页是对学院的说明。课程还没有写。现在每个方法以运行时里 `methods/` 下的方法页为准，学习方式是学习模式和试验场的引导之旅。

## 一节课

每个方法一课。每课有：

1. **用大白话讲清思想。**
2. **一个著名的真实案例**，附来源和日期。
3. **它背后的人**，以及该读的原始文献。
4. **一道练习**，它本身就是一句用在学习者自己生活里某件事上的问法。

不编造引语。每个案例在课程发布之前，都与它的来源核对过。

## 路径

| 路径 | 给谁 | 课程 |
|---|---|---|
| **七天走完七个阶段** | 第一周 | 入门七法：透视、第一性原理、反过来想、杠杆、最佳实践、做成作品、复盘 |
| **像实践者一样思考** | 喜欢从别人怎样做事里学的人 | 马斯克五步法、大野耐一与丰田之道、高德拉特、戴明、芒格、雅各布斯、瓦克、博伊德、费曼 |
| **系统科学家** | 想要正式骨架的人 | 维纳、阿什比、福瑞斯特与斯特曼、西蒙、贝塔朗菲、比尔、切克兰德与丘奇曼、梅多斯、霍兰、斯诺登 |

## 分级书单

从这里开始：德内拉·梅多斯《系统之美》（2008）；艾利·高德拉特《目标》（1984）；彼得·圣吉《第五项修炼》（1990）。

然后：大野耐一《丰田生产方式》（1978）；W. 爱德华兹·戴明《走出危机》（1986）；霍华德·马克斯《投资最重要的事》（2011）；简·雅各布斯《美国大城市的死与生》（1961）；赫伯特·西蒙《人工科学》（1969）。

更深：约翰·斯特曼《商务动态分析》（2000）；W. 罗斯·阿什比《控制论导论》（1956）；斯塔福德·比尔《企业的大脑》（1972）；彼得·切克兰德《系统思维，系统实践》（1981）；埃莉诺·奥斯特罗姆《公共事物的治理之道》（1990）；约翰·霍兰《隐秩序》（1995）。

完整的人物与著作清单，是设计文档的附录 A。

## 等级

等级沿着旅程，只能靠证据获得：学习者预见了一个结构、独立用了某个方法，或用自己的话讲清楚了（运行时里的 `system/growth.md`）。

怎样写一节课或一篇人物介绍，见 [CONTRIBUTING.zh-CN.md](../CONTRIBUTING.zh-CN.md)。
