# Changelog

This project follows [Semantic Versioning](https://semver.org/). Pre-release versions test real use before a stable release while keeping every artifact complete, installable, inspectable, and recoverable.

## 0.1.0-alpha.1 — 2026-11-22

The first bilingual pre-release of the natural-language open-system runtime.

- Centers every run on the current runnable system instance.
- Establishes models of system, relation, capability, runtime, and evolution.
- Forms the seven-layer architecture: `core / runtime / system / engines / capabilities / adapters / experience`, while the complete main entry continues to carry the product's spirit and runtime semantics on its own.
- Realizes the runtime as seven composable responsibilities—activate, recover, compose, observe, act, verify, and update.
- Lets understanding, action, and capability-building loops recurse, jump, and run in parallel.
- Preserves four surprises, five capability engines, seven capabilities, the two shores of understanding, works, and user-owned systems.
- Makes methods, routes, and system patterns cognitive resources called on demand.
- Includes 23 core methods, 7 advanced lenses, 10 system patterns, and 8 practitioner routes.
- Includes complete English and Chinese Skills, Playgrounds, system examples, and *The Core Sample of the AI Industry*.
- Rebuilds both project and in-Skill entry experiences around real work, unique difference, installation, the user journey, the runtime panorama, and shared works, with language-native desktop and mobile visuals.
- Includes zero-dependency installation, safe updates, recoverable removal, bilingual packages, and published checksums.
- Unifies the public Skill name as `open-x-sys` at version `0.1.0-alpha.1`.
