# Optional provider reviews

[Chinese](README.zh-CN.md) · [Dependency guide](../../skills/open-x-sys/deps/DEPENDENCIES.md)

The original runtime's provider list and candidate status are retained in this release. No external provider is approved for default installation. The AI can work with the capabilities already available in its host.

The lock file records exact candidate versions and checksums. A candidate is not a bundled capability. Review contributions include the publisher, pinned version, license, required runtimes, complete content review and a real task result. See the [Kit criteria](../../skills/open-x-sys/kit/KIT.md).

Share review evidence in an issue or pull request. Approval applies to the version reviewed.
