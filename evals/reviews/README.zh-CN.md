# 可选提供者审查

[English](README.md) · [依赖说明](../../skills/open-x-sys.zh-CN/deps/DEPENDENCIES.md)

本版保留原运行时的提供者清单与候选状态，没有获准默认安装的外部提供者。AI 可以使用当前工具中已有的能力。

锁定文件记录候选的确切版本与校验值；候选不等于内置能力。审查贡献包含发布者、锁定版本、许可证、所需运行环境、完整内容审查与真实任务结果，参见 [Kit 标准](../../skills/open-x-sys.zh-CN/kit/KIT.md)。

通过 Issue 或 Pull Request 提交依据。批准只针对已审查的那个版本。
