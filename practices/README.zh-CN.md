# 实践

[English](README.md)

人们在自己的工作里验证过、并愿意分享的实践，每一项都带着它的条件与证据。

**现在还没有分享的实践。** 只有真的有人用过、并记下了发生了什么，一项实践才会被列出。

## 一项分享的实践包含什么

分享的实践，是去掉了一切个人内容的实践记录（见运行时里的 `engines/practice.md`）。它让读者能判断它适不适合自己：

- 这项实践是什么：组成、连接、顺序、触发条件；
- 它服务于哪个目标；
- **它是在什么条件下使用的**：可用的时间、预算、技能、工具、规模；
- 证据，以及证据的种类：测到的、别人报告的，还是推出来的；
- 成本；
- 结果，带日期；
- 切换条件：什么时候该坚持、调整或更换；
- 谱系，如果它是从另一项分享的实践改来的。

## 规矩

- 没有条件的实践只是通用建议，不收。
- 结果照实报告，包括不管用的部分。
- 实践不是脚本。它停在原则，和决定成败的那几个决策上。
- 不放任何个人内容：没有人名、雇主、私人路径或连接的细节。
