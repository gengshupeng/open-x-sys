# How OpenXSys fits together

[Chinese](OVERVIEW.zh-CN.md) · [Project introduction](../README.md)

OpenXSys is a natural-language Skill for understanding systems, making judgments, creating useful work and improving through use. The person describes a goal; the AI chooses how to approach it.

## How the AI uses the documents

The entry explains the whole capability and points to the relevant pages. As the task develops, the AI reads the approaches and output guidance it will actually use. It can reuse pages still available in context and reread them when resuming after a context change.

A visible route describes the methods actually used. Running signals explain what the AI is doing and why. The person can steer, ask another question or request a different approach at any point.

## Files and capabilities

The installed Skill and the person's systems are separate. The person chooses where their systems live; ordinary files preserve understanding, practices and work for later use.

OpenXSys can work with tools and Skills already available in the host. Optional provider status is recorded in the [dependency guide](../skills/open-x-sys/deps/DEPENDENCIES.md).
