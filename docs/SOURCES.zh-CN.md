# 来源与转述说明

[English](SOURCES.md) · [项目介绍](../README.zh-CN.md)

OpenXSys 借鉴系统科学与顶尖实践者的思考方式。每个[方法页面](../skills/open-x-sys.zh-CN/methods)和[高手路线](../skills/open-x-sys.zh-CN/routes/masters)都写明来源，并说明本项目的转述范围。

这些来源包括维纳、阿什比、福雷斯特、西蒙、贝塔朗菲、比尔、圣吉和梅多斯等人的系统研究，以及大野耐一、戴明、高德拉特、芒格、博伊德、费曼等人的思考与实践。

## 放回来源的语境

部分路线是 OpenXSys 对相关思想的编排，页面会说明。具体例子与仍待确认的出处，保留在相关页面的来源说明中。

研究成果应区分来源陈述、估算、解释与未来情景，并保留日期、单位、来源链接和重要判断的推导依据。

## 精选产业研究案例

[AI 产业案例](../gallery/ai-industry/README.zh-CN.md)记录作者提供的一次真实产出。英文版翻译原始报告，数字、判断与情景属于这一份带日期的成果；运行说明记录了所用工具、模型和提示词。

## 提交修正

在 Issue 或 Pull Request 中提供页面、原说法、一手来源与建议改法。修改时同步完整中英文版本。
